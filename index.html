Dúvidas frequentes

Preciso saber escrever prompts?

Não. No modo fácil, você digita apenas o assunto e o Intorná cria o prompt completo para copiar no ChatGPT.

Minha conta ChatGPT Plus serve como chave de API?

Não. ChatGPT Plus e API OpenAI são serviços separados. Você pode usar o fluxo manual do ChatGPT sem chave; para gerar diretamente dentro do app, cada usuário precisa de sua própria chave de API com créditos.

Haverá cobrança durante o beta?

Não. O beta fechado é gratuito, a área de assinatura fica desativada e nenhum pagamento é criado.

Quem pode criar uma conta?

Nesta etapa, somente as três pessoas convidadas por Wagner, usando o código recebido.

Os dados ficam online?

Sim. Clientes, pedidos e criativos são sincronizados com o Supabase e isolados por estúdio. Leia a Política de Privacidade antes de participar.

Como envio uma sugestão ou erro?

Dentro do painel, use o botão “Feedback do beta”. Ele abre um formulário curto para explicar o que tentou, o que funcionou e onde encontrou dificuldade.
