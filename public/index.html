Dúvidas frequentes

Preciso saber programar?

Não. A plataforma foi desenhada para uso direto no celular ou computador.

A Intorná Pixels gera as fotografias?

Esta versão organiza a operação e monta a direção criativa. A geração das imagens é feita no gerador de IA escolhido pelo usuário.

Os dados ficam online?

A versão atual possui login, Central Administrativa e ambientes separados por estúdio no navegador. A sincronização entre aparelhos exigirá a futura conexão com banco de dados online.

Posso mudar meus pacotes e preços?

Sim. O painel permite cadastrar pacotes, preços, quantidade de fotos e extras.

Posso enviar fotos extras com marca-d’água?

Sim. O módulo de prévias aplica texto ou logo em lote, gera um ZIP e prepara a mensagem de upsell para o WhatsApp.

Gestão simples para quem está começando a vender ensaios de fotografia por IA.
